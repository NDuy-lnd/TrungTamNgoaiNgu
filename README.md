# 🌐 Hệ thống quản lý trung tâm ngoại ngữ

## 📌 Giới thiệu

Website quản lý trung tâm ngoại ngữ được xây dựng nhằm hỗ trợ quản lý học viên, giáo viên, khóa học và các hoạt động giảng dạy, học tập tại trung tâm.

Hệ thống có giao diện riêng cho ba vai trò: **Quản trị viên, Giáo viên và Học viên**.

## 🚀 Chức năng chính

**Quản trị viên (Admin)**
- Quản lý học viên và giáo viên.
- Quản lý khóa học, lớp học và lịch học.
- Phân công giáo viên, xếp học viên vào lớp.
- Theo dõi thống kê hoạt động của trung tâm.

**Giáo viên**
- Xem danh sách lớp được phân công.
- Theo dõi lịch giảng dạy.
- Điểm danh và nhập điểm cho học viên.
- Quản lý tài liệu học tập.

**Học viên**
- Xem các lớp học đang tham gia.
- Theo dõi lịch học và kết quả học tập.
- Xem lịch sử điểm danh.
- Xem tài liệu học tập.

## 🛠️ Công nghệ sử dụng

| Thành phần | Công nghệ |
|---|---|
| Frontend | ReactJS, Vite, Ant Design |
| Backend | Python, FastAPI |
| Database | MySQL |
| API | RESTful API |
| Authentication | JWT |
